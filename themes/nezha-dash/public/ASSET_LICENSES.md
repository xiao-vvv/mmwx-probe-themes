# Third-party visual assets

`farm-background.png` is based on `Background.png` from "Tiles And Background
Image" by ScratchIO. The source is published under CC0 1.0:

- https://opengameart.org/content/tiles-and-background-image
- https://creativecommons.org/publicdomain/zero/1.0/

`farm-background-ai.webp` was generated specifically for this project with
`gpt-image-2`; it does not contain third-party source artwork.

`beauty-background.webp` was generated specifically for this project with
`gpt-image-2` through the user-provided image API. It is stored locally and
does not hotlink or incorporate third-party website assets.

`beauty-background-desktop-v2.png` and `beauty-background-mobile-v2.png` are
user-provided originals. They are copied byte-for-byte without resizing,
re-encoding, or compression and are used only by the `nezha-beauty` skin.

The Nezha Dash source license is preserved in the theme root `LICENSE` file.
